# 🛒 Meesho Clone (MERN Stack)

## 🚀 Features

* User Authentication (Login/Signup)
* Product Listing
* Add to Cart
* Admin Panel (in progress)

## 🛠 Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB

## 📦 Installation

```bash
git clone https://github.com/your-username/meesho-clone.git
cd meesho-clone
npm install
```
